Topic 1: Introduction to Information System

What is System?

System is a set of related components that produces specific results.

Information System

Moreover, businesses use many types of systems to operate their daily businesses such as inventory control, human resources, account and so on. These information system can handle day to day task as well as help managers to perfom better decisions making

Hardware

Is the physical layer of the information system. Hardware example can include servers, workstations, networks, scanners, digital capture devices, telecommunications equipment, fiber-optic cables, mobile devices and so on.

Software

Programs that control the hardware and produce the desired information or results.

System Software:

  • Operating System

  • Security System

  • Device Drivers

Application Software:

  • Enterprise Application

  • Legacy System

  • Horizontal System

  • Vertical System

Data

Data is raw facts that an IS transforms into useful information. Data has no inherent meaning and cannot be used for making decision. Data must be accurate, relavance, reliable, complete, and timely before turning into usefull information.

Process

Process can be describe as tasks and business functions that users, managers, and IT staff members perform to achieve specific results. Process represent the actual day to day business operation. For example, generating report, accounting, upload documents and so on.

People

People can be describe as having an interest in an IS. A user is a person who communicates with an IS or uses the information that it generates. For example, stakesholders, customers, accountant, managers and so on.
