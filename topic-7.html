User interface (UI) prototyping is an early phase of UI development where you create a digital mock-up of a future customer-facing interface.

Input Devices Example

Input devices can be very traditional, or based on the latest technology. Such as keyboard, mouse, trackpad and so on.

Input Design Objectives

When design your buttons, fill in form and so you may apply the following concept to imporve user experiences.

  • Ease of Use

  • Accuracy

  • Effectiveness

  • Attractiveness

  • Simplicity

  • Consistency

Types of Report



Detail Report

1. Produces one or more lines of output for each record processed.
2. Can be quite lengthy.
3. A better alternative might be an exception report.



Exception Report

1. Displays only those records that meet a specific condition or conditions.
2. Useful when the user wants information only on records that might require action, but does not need to know the details.
3. Suffiecient Information for decision making.

Summary Report

1. Upper-level managers often want to see total figures and do not need supporting details.
2. Short and straighforward.
2. Summary of everything.



Output Design Objectives

When design your reports, output processes and so you may apply the following concept to imporve user experiences.

  • Ease of View

  • Accuracy

  • Repeating Fields

  • Page Headers and Footers

  • Simplicity

  • Consistency
